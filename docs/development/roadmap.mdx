# Roadmap

Recode 当前优先保持 CLI、Provider、Goal、Workflow 和 ACP 的稳定性。后续方向按
用户价值、架构展示价值和可验证性选择，不承诺固定发布日期。

## 近期方向

- 可重建索引的本地项目记忆与引用检索
- 统一、版本化的 Tool capability contract
- 更完整的 TUI、长会话和跨平台发布 E2E
- 明确边界的 sandbox profiles 与会话恢复
- 本地 session dashboard 和代码库增量索引

## 准入规则

新增功能必须先明确用户场景、最小范围、配置与数据格式、安全边界、失败行为、
测试方式和公开文档。只有公开入口、错误处理、自动化测试、构建产物验证和文档
同时完成，能力才进入稳定产品面。
