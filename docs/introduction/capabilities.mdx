# 能力概览

Recode 是一个 API-key-first 的终端 coding agent。交互式 TUI、非交互输出和
ACP stdio 入口共享同一套流式 Agent loop、Provider、权限与会话持久化。

## Agent 运行时

- 流式文本与 thinking、工具调用和上下文压缩
- JSONL 会话、继续、恢复、分支、重命名和标签
- 默认、接受编辑、计划和 bypass 等权限模式
- 持续 Goal、checkpoint、token 预算和恢复
- 声明式多 Agent DAG、并发调度、结构化输出和 worktree 隔离

## 工具与代码智能

- 文件读取、编辑、写入和 Notebook 修改
- Shell、Glob、Grep、Web Fetch 和 Web Search
- Git worktree、任务管理、自定义 Agent 和 Skills
- MCP、Hooks、Plugins 与可配置 LSP

## Provider

Recode 支持 Anthropic Messages API、OpenAI-compatible Chat Completions、CPA、
Bedrock、Vertex 和 Foundry。`/provider` 可以在外部 `.claude` 配置与 Recode 的
只读 Provider catalog 之间切换；`/model` 管理当前会话的模型和 effort。

## 客户端入口

- `recode`：交互式终端
- `recode -p`：脚本和 CI 使用的非交互模式
- `recode --acp`：编辑器和其他 ACP Client 使用的标准 JSON-RPC stdio
