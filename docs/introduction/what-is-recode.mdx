## 一句话定义

Recode 是一个运行在命令行终端里的 AI 编程 Agent。你用自然语言描述需求，它可以读取代码、修改文件、执行命令并搜索项目。本地工具在你的机器上执行，模型、Web 和 MCP 能力可能访问你配置的外部服务。

## 它能做什么

- **对话式编程**：像和同事聊天一样描述需求，AI 直接动手实现
- **理解整个项目**：自动读取项目结构、git 历史、配置文件，建立项目全景认知
- **操作你的电脑**：读写文件、执行 shell 命令、搜索代码——不只是给建议，而是真正动手
- **控制操作边界**：权限规则决定哪些操作需要确认、自动放行或禁止，支持可选沙箱

## 它和 ChatGPT / 普通聊天机器人的区别

| | 普通聊天 AI | Recode |
|---|---|---|
| 运行环境 | 云端网页 | 你的本地终端 |
| 能做什么 | 回答问题、生成文本 | 直接操作你的项目文件和命令行 |
| 项目理解 | 你需要手动粘贴代码 | 自动读取整个项目上下文 |
| 安全性 | 无需考虑 | 多层权限保护 |

## 一次典型的交互流程

1. 你在终端输入自然语言需求
2. Recode 分析你的项目上下文
3. 它决定使用哪些工具（读文件？执行命令？）
4. 每个操作请求你确认（或根据规则自动放行）
5. 执行完成后，把结果反馈给 AI，AI 决定下一步
6. 循环，直到任务完成
