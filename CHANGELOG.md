# Changelog

All notable changes will be documented in this file. Recode follows Semantic
Versioning after the first stable release.

## 0.0.1 - 2026-07-16

### Added

- Interactive and non-interactive coding-agent runtimes with API-key-first
  Provider routing.
- Persistent Goals, multi-agent workflow orchestration, worktree isolation,
  MCP, skills, plugins, hooks, and LSP integration.
- ACP stdio sessions with streaming updates, permissions, cancellation, and
  JSONL-backed resume.
- Checksum-verified standalone releases for macOS and Linux with a maintained
  curl installer.
- Reproducible Bun builds, deterministic tests, provider/ACP E2E suites, and
  public architecture documentation.
